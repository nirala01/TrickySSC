1. Concepts in brief

Square and square root

The square of a number is the number multiplied by itself: 7² = 49. Going backwards, the square root of 49 is 7. A number like 49, whose square root is a whole number, is a perfect square. Every positive number has two square roots (+7 and −7), but the sign √ always means the positive one.

Cube and cube root

The cube of a number is the number used three times in a product: 4³ = 64, and ∛64 = 4. Unlike square roots, cube roots work for negative numbers too: (−4)³ = −64, so ∛(−64) = −4.

Prime factorisation — the method that always works

Break the number into primes. For a square root, make pairs of equal primes and take one from each pair. For a cube root, make groups of three. Anything left without a partner tells you the number is not a perfect square (or cube) — and exactly what to multiply or divide by to make it one.

Example of the method √1764: 1764 = 2² × 3² × 7². One from each pair: 2 × 3 × 7 = 42.

3. Shortcuts that save time

  • Squares ending in 5: for n5, write n(n+1) then 25. 75² → 7×8 = 56 → 5625.
  • Near 50: (50 + x)² = 2500 + 100x + x². 53² = 2500 + 300 + 9 = 2809.
  • Near 100: (100 + x)² = 10000 + 200x + x². 97² = 10000 − 600 + 9 = 9409.
Square root of a perfect square in 10 seconds √7056: the last digit 6 means the root ends in 4 or 6. The first pair 70 lies between 8² = 64 and 9² = 81, so the root is 8_. Since 85² = 7225 is bigger than 7056, take the smaller choice: 84.
Cube root of a perfect cube ∛357911: last digit 1 → root ends in 1. Drop the last three digits: 357 lies between 7³ = 343 and 8³ = 512, so the first digit is 7. Answer 71.

4. Solved examples

Example 1 Smallest number by which 1176 must be multiplied to make it a perfect square?
1176 = 2³ × 3 × 7². Unpaired: one 2 and one 3. Multiply by 2 × 3 = 6 (1176 × 6 = 7056 = 84²).
Example 2 √0.0016 + ∛0.008 = 0.04 + 0.2 = 0.24.
Example 3 Least number to subtract from 2000 to get a perfect square?
44² = 1936 and 45² = 2025. So subtract 2000 − 1936 = 64.

More solved examples (exam level)

Example 4 Smallest number by which 2916 must be divided to get a perfect cube?
2916 = 2² × 3⁶. The 3s make two full triplets; the 2² is left over. Divide by 4 to get 729 = 9³.
Example 5 √(248 + √(51 + √169)): work from inside. √169 = 13 → 51 + 13 = 64 → √64 = 8 → 248 + 8 = 256 → 16.
Example 6 Greatest 4-digit perfect square? 100² = 10000 has five digits, so the answer is 99² = 9801.
Example 7 √(12 + √(12 + √(12 + …))): since 12 = 3 × 4, the value is the larger factor, 4. (Check: x² = 12 + x gives x = 4.)

5. Practice questions (with answers)

Tap a question to see its answer.

Q1. Find √1849.

Answer: 43 (ends in 9 → root ends in 3 or 7; 40² = 1600 and 45² = 2025, so 43).

Q2. Find ∛46656.

Answer: 36 (ends in 6 → root ends in 6; 46 lies between 3³ = 27 and 4³ = 64).

Q3. Least number to be added to 7000 to make it a perfect square?

Answer: 56 (83² = 6889, 84² = 7056).

Q4. Smallest number by which 108 must be multiplied to get a perfect cube?

Answer: 2 (108 = 2² × 3³, so one more 2 is needed: 216 = 6³).

Q5. Find √0.000064.

Answer: 0.008 (six decimal places → three in the root; √64 = 8).

6. Traps to avoid

  1. √(a + b) ≠ √a + √b. √(9 + 16) = 5, not 7.
  2. √0.9 ≠ 0.3 — because 0.3² = 0.09. An odd number of decimal places can never be a perfect square.
  3. Ending in 1, 4, 5, 6, 9 or 0 does not prove a square — check the digit sum too (e.g., 1234 is not a square).
  4. For "least number to add", go to the next square up; for "subtract", go to the square below.
  5. The cube root of a negative number is negative: ∛(−343) = −7.
