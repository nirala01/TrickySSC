1 Drop every file for every mock

Select or drag in all files at once — as many mocks as you like. Files are grouped into mocks automatically by their filename prefix (e.g. ssc-cgl-2025-mock-12-). Each mock wants 4 CSVs (questions-EN / questions-HI / solutions-EN / solutions-HI) and, if it has figure questions, one figures .docx. A .docx whose name carries no prefix is matched by its heading line (e.g. SSC CGL 2025 Mock Test-12 — Image / Figure Questions), or you can assign it by hand below.

3 Run

For each selected mock this uploads the figure images once, then writes all 200 question documents (100 EN + 100 HI) with their options, answer key, explanation, trick, concept, image URLs and mockId already merged in — plus both mock_tests cards. Writes go out in batches, and document IDs are derived from the mockId, so a re-run repairs a mock instead of duplicating it.
