What You Will Practice in the Algebraic Result Chapter

Core topics

  • The ladder up: square the bracket and adjust by 2, and why each squaring doubles the power
  • The ladder down: add 2 and take the root, and which 2 to use for a sum or a difference
  • The root level — √x + 1/√x and where it lands
  • Cube rules for sums and differences, and the sixth power as the square of the cube
  • Fifth, seventh and other odd powers by multiplying two levels
  • Quadratic equations that hide the pair, and the constant-term sign rule
  • Single fractions such as (x2+1)/x that split into a reciprocal sum
  • Surd values, and rationalising to find the reciprocal
  • Scaled and shifted terms: 3p with 1/3p, x/5 with 5/x, (x−3) with 1/(x−3)
  • Self-referential definitions such as x = 1/(x − 4)
  • Crossing between sum and difference, and ranges that decide the final sign
  • Values with no real solution, and power cycles for x50 and x99

Solved Examples — SSC CGL Algebraic Result

Q1. If x + 1/x = 3, find x8 + 1/x8.
Square and subtract 2 each time: 9 − 2 = 7, then 49 − 2 = 47, then 2209 − 2. The −2 applies at every step. Answer: 2207
Q2. If x2 − 9x + 1 = 0 and x ≠ 0, find x + 1/x.
The constant is 1, so divide every term by x: x − 9 + 1/x = 0. Answer: 9
Q3. If x + 1/x = √13 and x > 1, find x3 − 1/x3.
Cross over: (x − 1/x)2 = 13 − 4 = 9, so x − 1/x = 3. Then k3 + 3k = 27 + 9. The surd disappears because 13 − 4 is a perfect square. Answer: 36
Q4. If x2 + 1/x2 = 27 and 0 < x < 1, find x − 1/x.
27 − 2 = 25, so the size is 5. But x is small and 1/x is large, so the difference is negative. Answer: −5
Q5. If x2 + x + 1 = 0, find x99 + 1/x99.
Multiplying by (x − 1) gives x3 = 1, so powers repeat every 3. 99 is a multiple of 3, so x99 = 1. Answer: 2

How to Prepare Algebraic Result for SSC CGL

  1. Learn the ladder before anything else. Square and subtract 2 going up, add 2 and take the root coming down — that one pair of moves solves most of the chapter.
  2. Fix the sum-and-difference rule. Sums subtract the adjustment, differences add it, for both squares and cubes. Almost every wrong option in this chapter comes from swapping them.
  3. Read the constant term of a quadratic first. A +1 constant gives a reciprocal sum, a −1 constant gives a difference, and a common factor must be cleared before either works.
  4. Remember that odd powers are not on the ladder. Multiply two levels and subtract the leftover level: level 2 times level 3 gives level 5 plus level 1.
  5. Check the range before the final square root. With 0 < x < 1 the difference is negative, and the right-sized wrong-signed option is always offered.
  6. Do Level 1 untimed, the same day you learn the ladder. The aim is correct recall, not speed.
  7. Move to Level 2 with the 30-minute clock on. A climb that takes more than twenty seconds means you are still deriving the rule instead of applying it.
  8. Study it right after algebraic formula. The cube rule carries straight over from algebraic formula, and the chapter notes are best read beside the tests.
  9. Verify against a real paper. Once Level 2 is consistent, attempt a previous year paper and then a full mock test under locked sectional timing.

SSC CGL Algebraic Result — Frequently Asked Questions

How do I find x2 + 1/x2 from x + 1/x?
Square the given value and subtract 2. If the given is a difference instead, square it and add 2. The adjustment is always exactly 2 because x × 1/x = 1.
What is the formula for x3 + 1/x3?
It is k3 − 3k, where k = x + 1/x. For the difference it is k3 + 3k with k = x − 1/x. Sums subtract the correction and differences add it.
How do I get x + 1/x from a quadratic equation?
If the constant term is 1, divide every term by x. So x2 − 9x + 1 = 0 becomes x − 9 + 1/x = 0, giving x + 1/x = 9. A constant of −1 gives a difference instead, and a common factor must be cleared first.
When is x − 1/x negative?
When 0 < x < 1, because then 1/x is the larger term. It is also negative when x < −1. A sum such as x2 + 1/x2 is always positive, so only the final step to a difference depends on the range.
How do I handle very high powers such as x99?
Look for a cycle. If x2 + x + 1 = 0 then x3 = 1 and powers repeat every 3. If x2 − x + 1 = 0 then x3 = −1 and x6 = 1, so they repeat every 6. Reduce the exponent by the cycle and evaluate the level that is left.
