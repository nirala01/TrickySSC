बीजीय व्यंजक एवं सर्वसमिकाएँ

सूत्र, ट्रिक और गलतियाँ एक पेज पर · मात्रात्मक अभियोग्यता

इस शीट में

  1. मुख्य सर्वसमिकाएँ
  2. समय बचाने वाले शॉर्टकट
  3. हल किए गए उदाहरण
  4. इन गलतियों से बचें

सर्वसमिकाएँ भारी गणना को एक पंक्ति के प्रतिस्थापन में बदल देती हैं। पैटर्न सीखिए, पहचानिए कि प्रश्न में कौन-सी छिपी है, और संख्याएँ रख दीजिए।

1. मुख्य सर्वसमिकाएँ

#सर्वसमिका
1(a + b)² = a² + 2ab + b²
2(a − b)² = a² − 2ab + b²
3a² − b² = (a + b)(a − b)
4(a + b)³ = a³ + b³ + 3ab(a + b)
5(a − b)³ = a³ − b³ − 3ab(a − b)
6a³ + b³ = (a + b)(a² − ab + b²)
7a³ − b³ = (a − b)(a² + ab + b²)
8(a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
9a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)
10यदि a + b + c = 0, तो a³ + b³ + c³ = 3abc

2. समय बचाने वाले शॉर्टकट

व्युत्क्रम जोड़े यदि x + 1/x = k: x² + 1/x² = k² − 2 और x³ + 1/x³ = k³ − 3k। यदि x − 1/x = k: x² + 1/x² = k² + 2।
  • यदि a + b + c = 0, तो a³ + b³ + c³ की जगह सीधे 3abc रखिए।
  • गोल संख्या के पास की संख्याओं में (a ± b)² लगाइए। 99² = (100 − 1)² = 9801।
  • x = 1 या 2 जैसा छोटा मान रखकर उत्तर जाँच लीजिए।

3. हल किए गए उदाहरण

उदाहरण 1 यदि x + 1/x = 5, तो x² + 1/x² = 25 − 2 = 23 और x³ + 1/x³ = 125 − 15 = 110।
उदाहरण 2 (105)² − (95)² = (105 + 95)(105 − 95) = 200 × 10 = 2000।
उदाहरण 3 यदि a + b = 7 और ab = 10, तो a² + b² = 49 − 20 = 29 और a³ + b³ = 343 − 3 × 10 × 7 = 133।
उदाहरण 4 यदि a + b + c = 0, तो (a³ + b³ + c³)/abc = 3।

4. इन गलतियों से बचें

  1. (a + b)² ≠ a² + b² — बीच का पद 2ab कभी छोड़ा नहीं जा सकता।
  2. (a − b)³ में चिह्न देखिए: यह −3ab(a − b) है।
  3. x − 1/x वाले प्रश्नों में वर्ग करने पर परिणाम में 2 जुड़ता है, घटता नहीं।
  4. a + b + c = 0 वाला शॉर्टकट केवल उसी शर्त पर लगता है।

इस अध्याय का अभ्यास कीजिए

चैप्टर टेस्टबीजीय व्यंजक एवं सर्वसमिकाएँ — लेवल 1 और लेवल 2, हल सहित सभी गणित नोट्समात्रात्मक अभियोग्यता के सभी अध्याय CGL पिछले वर्षअसली प्रश्न, शिफ्ट-दर-शिफ्ट पूरे मॉक टेस्टसमय के दबाव में अभ्यास

TrickySSC — निःशुल्क SSC परीक्षा तैयारी। SSC CGL, CHSL, CPO और MTS के लिए बीजीय व्यंजक एवं सर्वसमिकाएँ की एक पेज की पुनरावृत्ति शीट।
