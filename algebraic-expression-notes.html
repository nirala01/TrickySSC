Algebraic Expression & Identities

Formulas, tricks and traps on one page · Quantitative Aptitude

On this sheet

  1. Key identities
  2. Shortcuts that save time

Identities turn heavy calculation into one-line substitution. Learn the patterns, spot which one the question hides, and plug in the numbers.

1. Key identities

#Identity
1(a + b)² = a² + 2ab + b²
2(a − b)² = a² − 2ab + b²
3a² − b² = (a + b)(a − b)
4(a + b)³ = a³ + b³ + 3ab(a + b)
5(a − b)³ = a³ − b³ − 3ab(a − b)
6a³ + b³ = (a + b)(a² − ab + b²)
7a³ − b³ = (a − b)(a² + ab + b²)
8(a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
9a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)
10If a + b + c = 0, then a³ + b³ + c³ = 3abc

2. Shortcuts that save time

Reciprocal pairs If x + 1/x = k: x² + 1/x² = k² − 2, and x³ + 1/x³ = k³ − 3k. If x − 1/x = k: x² + 1/x² = k² + 2.
  • If a + b + c = 0, replace a³ + b³ + c³ by 3abc straight away.
  • For numbers close to a round figure, use (a ± b)². 99² = (100 − 1)² = 9801.
  • Check the answer by substituting a small value like x = 1 or 2.

3. Solved examples

Example 1 If x + 1/x = 5, then x² + 1/x² = 25 − 2 = 23, and x³ + 1/x³ = 125 − 15 = 110.
Example 2 (105)² − (95)² = (105 + 95)(105 − 95) = 200 × 10 = 2000.
Example 3 If a + b = 7 and ab = 10, then a² + b² = 49 − 20 = 29 and a³ + b³ = 343 − 3 × 10 × 7 = 133.
Example 4 If a + b + c = 0, then (a³ + b³ + c³)/abc = 3.

4. Traps to avoid

  1. (a + b)² ≠ a² + b² — the middle term 2ab is never optional.
  2. Watch the sign in (a − b)³: it is −3ab(a − b).
  3. In x − 1/x problems, squaring adds 2 to the result, not subtracts.
  4. The a + b + c = 0 shortcut works only for that exact condition.
