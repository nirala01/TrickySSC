Identities turn heavy calculation into one-line substitution. Learn the patterns, spot which one the question hides, and plug in the numbers.

1. Concepts in brief

Expression, identity, equation

An expression like 3x² − 2x + 5 is a combination of terms. An identity is a statement true for every value of the letters, such as (a + b)² = a² + 2ab + b². An equation is true only for particular values, such as 2x + 3 = 7. SSC questions in this chapter mostly use identities to evaluate expressions without finding the letters.

Use what is given, not the letters

If the question gives a + b and ab, it wants you to build the answer from those two numbers, not to solve for a and b. Every symmetric expression — a² + b², a³ + b³, 1/a + 1/b — can be written using a + b and ab.

Conjugate values

When x = a + √b and a² − b = 1, the reciprocal 1/x = a − √b. So x + 1/x = 2a, which unlocks the reciprocal-pair shortcuts.

2. Key identities

#Identity
1(a + b)² = a² + 2ab + b²
2(a − b)² = a² − 2ab + b²
3a² − b² = (a + b)(a − b)
4(a + b)³ = a³ + b³ + 3ab(a + b)
5(a − b)³ = a³ − b³ − 3ab(a − b)
6a³ + b³ = (a + b)(a² − ab + b²)
7a³ − b³ = (a − b)(a² + ab + b²)
8(a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
9a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca)
10If a + b + c = 0, then a³ + b³ + c³ = 3abc

3. Shortcuts that save time

Reciprocal pairs If x + 1/x = k: x² + 1/x² = k² − 2, and x³ + 1/x³ = k³ − 3k. If x − 1/x = k: x² + 1/x² = k² + 2.
  • If a + b + c = 0, replace a³ + b³ + c³ by 3abc straight away.
  • For numbers close to a round figure, use (a ± b)². 99² = (100 − 1)² = 9801.
  • Check the answer by substituting a small value like x = 1 or 2.

4. Solved examples

Example 1 If x + 1/x = 5, then x² + 1/x² = 25 − 2 = 23, and x³ + 1/x³ = 125 − 15 = 110.
Example 2 (105)² − (95)² = (105 + 95)(105 − 95) = 200 × 10 = 2000.
Example 3 If a + b = 7 and ab = 10, then a² + b² = 49 − 20 = 29 and a³ + b³ = 343 − 3 × 10 × 7 = 133.
Example 4 If a + b + c = 0, then (a³ + b³ + c³)/abc = 3.

More solved examples (exam level)

Example 5 If x = 2 + √3, then 1/x = 2 − √3 and x + 1/x = 4. So x² + 1/x² = 16 − 2 = 14.
Example 6 If a − b = 3 and ab = 10: a² + b² = 9 + 20 = 29, and a³ − b³ = (a − b)³ + 3ab(a − b) = 27 + 90 = 117.
Example 7 If a² + b² + c² = ab + bc + ca, then a = b = c, so (a + b)/c = 2.
Example 8 If a + b + c = 6 and ab + bc + ca = 11, then a² + b² + c² = 36 − 22 = 14.

5. Practice questions (with answers)

Tap a question to see its answer.

Q1. If x − 1/x = 3, find x² + 1/x².

Answer: 11 (9 + 2).

Q2. Find 997² using an identity.

Answer: 994009 ((1000 − 3)²).

Q3. If a + b = 10 and ab = 21, find a² + b².

Answer: 58 (100 − 42).

Q4. If a = 2, b = 3, c = −5, find a³ + b³ + c³.

Answer: −90 (a + b + c = 0, so 3abc).

Q5. If x + 1/x = 3, find x³ + 1/x³.

Answer: 18 (27 − 9).

6. Traps to avoid

  1. (a + b)² ≠ a² + b² — the middle term 2ab is never optional.
  2. Watch the sign in (a − b)³: it is −3ab(a − b).
  3. In x − 1/x problems, squaring adds 2 to the result, not subtracts.
  4. The a + b + c = 0 shortcut works only for that exact condition.
