How these tests work

Every question here was asked in a real SSC paper — SSC CGL, SSC CHSL and SSC GD. A chapter's questions from all exams sit together, in paper order: Test 1 holds the oldest papers, the last test the newest. When a new paper of any exam is uploaded and tagged, its questions join the end of the chapter and a new test appears once 25 have collected, so tests you have already attempted never change.

Tests run with a 15-minute timer by default (you can switch it off on the start screen), carry +2 / −0.5 marking like the chapter tests, and show a step-by-step solution for every question in English and Hindi. The exam, paper and shift are shown under every question.
