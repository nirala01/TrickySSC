Every missing number question comes down to two steps: find one rule that every complete row (or column) obeys, then apply it to the line with the question mark. The grid hides the rule, but the arithmetic is always simple once the rule is found — a sum, a product, a square, a fixed number added or taken away.

Marks are lost in three places. The first is trusting a rule that fits only one row — with one row, many rules fit by chance, and that chance value is usually among the options. The second is reading only across when the pattern runs down the columns. The third is breaking BODMAS inside the rule, for example working a × b + c as a × (b + c).

What You Will Practice in the Missing Number Chapter

One-step rules

  • c = a + b, c = a − b and c = a × b, across the rows or down the columns
  • The same rules with a fixed number added or taken away (c = a × b − 3)
  • (a + b) × k, (a − b) × k, k × a ± b and a × b ÷ k
  • The middle number as the average of the outer two, and rows with the same total

Squares, cubes and mixed rules

  • a² ± b, a² + b², a² − b², (a + b)² and (a − b)²
  • a³ ± b and ab ± (a + b)
  • The result placed first or in the middle of the line instead of last

Four numbers in a line

  • (a + b) × c, (a − b) × c, a × b ± c and a × b × c
  • a × b ÷ c and a² + b² ± c
  • Four numbers with a constant total

Rules worth knowing instantly

What you seeWhat to try first
Last number a little bigger than the first twoa + b, then a + b ± a small constant
Last number much bigger than the first twoa × b, then a × b ± a constant, then (a + b) × k
Last number near 25, 49, 64, 100, 125 …Squares or cubes of the given numbers
Last number smaller than the othersa − b, a ÷ b or an average
No rule works across the rowsRead the columns from top to bottom
Four numbers in a line(a + b) × c and a × b ± c

A rule is accepted only when it works on every complete line in the same direction — check two rows (or two columns) before you use it.

The three mistakes that cost the most marks

  • Stopping after one row. 5, 7, 12 fits a + b, but if the next row is 6, 9, 54 the rule is not addition.
  • Never trying the columns. When the rows show nothing, the pattern almost always runs down the columns.
  • Breaking BODMAS inside the rule. a × b + c is (a × b) + c, not a × (b + c).

Solved Examples — SSC CGL Missing Number

Q1. Find the missing number. Row 1: 6, 7, 42  |  Row 2: 14, 5, 70  |  Row 3: 4, 12, ?
In each row, third = first × second: 6 × 7 = 42 and 14 × 5 = 70. So 4 × 12 = 48. Answer: 48
Q2. Find the missing number. Row 1: 9, 6, 11  |  Row 2: 4, 3, 7  |  Row 3: 26, 18, ?
The rows show no common rule, so read the columns top to bottom: bottom = (top + middle) × 2. (9 + 4) × 2 = 26 and (6 + 3) × 2 = 18. So (11 + 7) × 2 = 36. Answer: 36
Q3. Find the missing number. Row 1: 3, 4, 25  |  Row 2: 5, 2, 29  |  Row 3: 6, 3, ?
Third = a² + b²: 9 + 16 = 25 and 25 + 4 = 29. So 36 + 9 = 45. Answer: 45
Q4. Find the missing number. Row 1: 4, 5, 8, 72  |  Row 2: 7, 3, 6, 60  |  Row 3: 9, 2, 5, ?
Fourth = (first + second) × third: (4 + 5) × 8 = 72 and (7 + 3) × 6 = 60. So (9 + 2) × 5 = 55. Answer: 55

How to Prepare Missing Number for SSC CGL

  1. Start with the largest number in each complete line. Its size tells you whether to try addition, multiplication or squares.
  2. Write the rule with letters. “c = a × b − 3” is easy to test on every line; a vague idea is not.
  3. Check two complete lines before answering. One line proves nothing; the option that fits only one line is the usual trap.
  4. If the rows fail, turn to the columns. Read them from top to bottom with the same letters.
  5. When the question mark feeds the rule, test the options. Put each option into the rule and keep the one that gives the known result.
  6. Do Level 1 untimed first, then with the 15-minute clock. Move to Level 2 once Level 1 is steady, and then check yourself on a previous year paper.

SSC CGL Missing Number — Frequently Asked Questions

How many missing number questions are asked in SSC CGL?
Usually one, sometimes two, in a Tier I reasoning section, and the same matrix questions appear in SSC CHSL. Once the checking habit is fixed, they are quick marks.
What is a missing number matrix question?
A grid of numbers, usually 3 by 3 or 3 by 4, with one cell replaced by a question mark. Every complete row (or every complete column) follows the same rule, and you use that rule to find the missing number.
How do I know whether the rule runs along rows or down columns?
Try the rows first. If no simple rule fits both complete rows, read the columns from top to bottom. A rule counts only when it works on every complete line in the same direction.
Which rules are most common?
The third number as the sum, difference or product of the first two, often with a fixed number added or subtracted; (a + b) × k; squares such as a² + b²; and, in four-column grids, rules like (a + b) × c or a × b + c. Rows with the same total also appear.
Why does a rule that works for one row give the wrong answer?
With only one row, many different rules fit by chance. The examiner often puts that chance value among the options. Always confirm the rule on a second complete row before using it.
How many questions are in each test?
Twenty-five questions per test, with an optional 15-minute timer and the real exam marking of +2 for a correct answer, −0.5 for a wrong one and 0 for an unattempted question.
Are the tests available in Hindi?
Yes. Questions, options, detailed solutions and shortcut tricks are available in Hindi, and you choose English or Hindi before the test starts.
What is the difference between Level 1 and Level 2?
Level 1 is set at real SSC CGL difficulty: 3 by 3 grids with one-step rules. Level 2 is harder than the exam: squares and cubes, four numbers in a line, the result placed first or in the middle, and the question mark more often on a number that feeds the rule, so you have to work backwards.
