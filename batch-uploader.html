1 Drop every file for every paper

Select or drag in all files at once — as many papers as you like. Files are grouped into papers automatically by their filename prefix (e.g. ssc-cgl-2023-jul18-s1-). Each paper wants 4 CSVs (questions-EN / questions-HI / solutions-EN / solutions-HI) and, if it has figure questions, one figures .docx. A .docx whose name carries no prefix is matched by its heading line (e.g. IMAGE QUESTIONS — 18-July-shift-1-2023), or you can assign it by hand below.

3 Run

For each selected paper this uploads the figure images once, then writes all 200 question documents (100 EN + 100 HI) with their options, answer key, explanation, trick, concept, image URLs and paperId already merged in — plus both papers cards. Writes go out in batches, and document IDs are derived from the paperId, so a re-run repairs a paper instead of duplicating it.
