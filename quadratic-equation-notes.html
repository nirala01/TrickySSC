Quadratic Equation

A quadratic has two roots. You rarely need to find them — the sum and product of roots, which come straight from the coefficients, answer most questions.

1. Key formulas

2. Shortcuts that save time

Factor by splitting the middle term x² − 7x + 12 = 0: find two numbers with sum −7 and product 12 → −3 and −4. Roots are 3 and 4.
  • If a + b + c = 0, one root is 1; if a − b + c = 0, one root is −1.
  • Roots reciprocal of each other: c = a.
  • Roots equal and opposite: b = 0.
  • For a nest like x = √(k + √(k + …)), square it and form x² − x − k = 0.

3. Solved examples

Example 1 Roots of x² − 5x + 6 = 0: sum 5, product 6 → 2 and 3.
Example 2 Roots of 2x² − 3x − 5 = 0: a − b + c = 2 + 3 − 5 = 0, so x = −1 is a root; product = −5/2, so the other root = 5/2.
Example 3 For x² − 6x + 8 = 0, α² + β² = 36 − 16 = 20.
Example 4 For which k does x² + kx + 9 = 0 have equal roots? D = k² − 36 = 0 → k = ±6.

4. Traps to avoid

  1. Sum of roots is −b/a, not b/a — keep the minus sign.
  2. Divide through by a before reading sum and product if a ≠ 1.
  3. A negative discriminant means no real roots, not no roots.
  4. When squaring both sides to remove a root, check every answer in the original equation.
