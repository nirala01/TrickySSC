Coding-decoding is a chapter of rules hidden in an example. A word, number or sentence is written in code, and the example given beside it tells you exactly how. Once you can see the rule — a letter shift, an opposite letter, a key read from coded words, a number formula, codes shared between sentences or a row-and-column position in a matrix — every question becomes mechanical.

Marks are lost in three places. The first is stopping after one step — many codes reverse a word and shift it, and an option that does only one of the two is always there to catch you. The second is losing count past Z — after Z comes A again, so Y + 3 is B. The third is trusting the first or last letter — options are made to differ in a single middle letter, so decode every position before you choose.

How Many Coding-Decoding Questions Are Asked in SSC CGL?

Coding-decoding gives two to three questions in a typical Tier I shift and a few more in Tier II Paper I, which makes it one of the four biggest reasoning chapters along with analogy, classification and series. Most questions take under a minute once the rule is spotted.

What You Will Practice in the Coding-Decoding Chapter

Letter coding

  • Uniform shift forward or back, including counting round past Z, and finding the shift from one coded pair
  • Alternating, growing, mirrored and repeating shifts — +1, +2, +3 …, +2/−2, odd numbers, cycles of three
  • Opposite letters (A↔Z, B↔Y), reversal, swapped halves and pairs, letters sorted into A–Z order
  • Two rules chained — reverse then shift, opposite then +1, pair-swap then mirror — and vowel / consonant conditions

Keys, numbers and sentences

  • Letter-to-letter and letter-to-digit keys from one or two words, codes written backwards, “which code is not right”
  • The code of one letter from jumbled codes of two or three words
  • Place-value strings (plain, reverse, doubled, ± position) and a word turned into one number
  • Sentence coding with numbers or code words, substitution chains and statement sufficiency

Symbols, matrices and conditions

  • Symbol coding for letters and digits, and two-stage symbol → digit → letter codes
  • Key tables, letter-cluster and letter-number analogies
  • Two-matrix and single-matrix row-column coding — find the set, the set that is not right, decode a set, count the codes
  • Rule tables with conditions on the first and last letters, number-to-number codes, two-part codes and step-by-step instructions

Rules worth knowing by heart

RuleWhat to remember
Place valuesA = 1 … Z = 26; landmarks E 5, J 10, O 15, T 20, Y 25 (“EJOTY”)
Opposite letterThe two places add to 27 — A–Z, B–Y, M–N
Reverse place value27 − place value, so A = 26 and Z = 1
Counting past ZAfter Z comes A: Y + 3 = B, and B − 3 = Y
DecodingUndo the steps in reverse order — the last step first
Sentence codingA word in two sentences takes the code those two codes share
Matrix codeRow number first, then column number; read the printed labels

Write place values under the word and its code before anything else — the differences show the rule at once.

The three mistakes that cost the most marks

  • Applying only one of two steps. If the code is reversed and shifted, the option that is only shifted is always offered.
  • Losing count past Z. X + 5 is C, not “off the end” — count round the circle.
  • Assuming a matrix is numbered 0–4 and 5–9. Rows or columns may run backwards or the two grids may be swapped — always read the label.

Solved Examples — SSC CGL Coding-Decoding Questions

Q1. If PENCIL is written as QFODJM, how is ERASER written in that code?
Every letter moves one place forward: P→Q, E→F, N→O, C→D, I→J, L→M. So ERASER becomes E→F, R→S, A→B, S→T, E→F, R→S. Answer: FSBTFS
Q2. If CAT is coded as XZG, how is DOG coded?
C 3 + X 24 = 27, A 1 + Z 26 = 27, T 20 + G 7 = 27 — each letter is replaced by its opposite. D↔W, O↔L, G↔T. Answer: WLT
Q3. If RAIN is written as 5371 and NEAR as 1835, how is EARN written?
From RAIN: R 5, A 3, I 7, N 1. From NEAR: N 1, E 8, A 3, R 5 — N, A and R agree, and E = 8. EARN = 8, 3, 5, 1. Answer: 8351
Q4. If ‘sky is blue’ is coded ‘ta ri mo’ and ‘blue is good’ is coded ‘mo ka ri’, what is the code for ‘sky’?
‘is’ and ‘blue’ appear in both sentences, and so do the codes ‘ri’ and ‘mo’. What is left in the first sentence is sky = ta. Answer: ta
Q5. If CAT = 24 and BAT = 23, what is DOG?
The code is the sum of the place values: C 3 + A 1 + T 20 = 24 and B 2 + 1 + 20 = 23. DOG = 4 + 15 + 7. Answer: 26

How to Prepare Coding-Decoding for SSC CGL

  1. Learn the place values and opposite pairs. EJOTY (5, 10, 15, 20, 25) and “pairs add to 27” turn every letter question into simple arithmetic.
  2. Write the differences under the example. Place values of the word and of its code, one under the other — the shift pattern is visible at once.
  3. Check the order of the letters before the letters themselves. If the code’s letters are the word’s letters shuffled, look for a reversal or a swap first.
  4. For keys and sentences, work in pairs. Compare two words or two sentences at a time and fix the shared item first.
  5. Decode backwards. Undo the last step first — and code your answer forward once to confirm it.
  6. Do Level 1 untimed first, then with the 15-minute clock. Move to Level 2 once Level 1 is steady, and then check yourself on a previous year paper.

SSC CGL Coding-Decoding Questions — Frequently Asked Questions

What is coding-decoding in SSC CGL reasoning?
It is the verbal reasoning chapter in which a word, number or sentence is written in a secret form by a fixed rule. You find the rule from the example given — a letter shift, opposite letters, a letter-to-digit key, a number formula, shared sentence codes or a row-column matrix — and use it to code or decode the asked word.
How many coding-decoding questions come in SSC CGL?
Usually two to three questions in every Tier I shift, and a few more in Tier II Paper I. Letter shifting, letter-digit keys and sentence coding are the most common forms; matrix coding appears regularly in CHSL and MTS.
How do I find the rule in a letter coding question quickly?
Write the place value (A = 1 … Z = 26) under each letter of the word and its code, then look at the differences. A constant difference is a uniform shift; differences that grow, alternate or mirror point to a progressive rule; pairs that add to 27 are opposite letters.
How are sentence coding questions solved?
Compare two sentences at a time. A word common to both sentences takes the code common to both codes. Fix the shared words first; whatever is left in a sentence belongs to its remaining word.
How do matrix (row-column) coding questions work?
Each letter is coded by its row number followed by its column number. A letter that appears in several cells has several correct codes, so in a 'find the set' question every code of the right option must land on the right letter, in order.
How many questions are in each coding-decoding practice test?
Twenty-five questions per test, with an optional 15-minute timer and the real exam marking scheme of +2 for a correct answer, −0.5 for a wrong one and 0 for an unattempted question.
Are the coding-decoding practice tests available in Hindi?
Yes. Questions, options, detailed solutions and shortcut tricks are available in Hindi, and you choose English or Hindi before the test starts.
What is the difference between Level 1 and Level 2?
Level 1 is set at real SSC CGL difficulty — one rule per question. Level 2 is harder than the exam: two rules chained together, rules you must work out from two or three examples, decoding with look-alike options, 'which code is NOT right' matrices and rule tables where more than one condition applies.
