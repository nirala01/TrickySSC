The last-digit rule for squares

Root ends in1 or 92 or 83 or 74 or 650
Square ends in149650

Every ending comes from a pair of digits, so the last digit narrows the root to two candidates and the decade picks between them. A number ending in 2, 3, 7 or 8 is never a perfect square; a square ending in 5 must end in 25; and a perfect square always ends in an even number of zeros.

Cubes, and why cube roots are easier

n3182764125216343512729100013311728
Cube ends in187456329018

The last digit of a cube identifies the last digit of its root uniquely — only 2, 3, 7 and 8 swap places, and the rest map to themselves. So for any perfect cube up to six digits: strike off the last three digits and the block that remains sits between two cubes, whose smaller root is the ten digit; the last digit of the number then gives the unit digit. ∛262144 → 262 lies between 216 and 343, so the ten digit is 6, and the number ends in 4, so the root is 64.

Decimals, and the one rule that covers them

The digits of the root never change — only the point moves. Given √0.5776 = 0.76, it follows at once that √57.76 = 7.6 and √0.005776 = 0.076, with no fresh working.

The add and subtract answers always sum to (k + 1)2 − k2 = 2k + 1, which makes a quick check. Cubes use the same layout with k3 and (k + 1)3.

Also worth memorising

  • A number with 2n or 2n − 1 digits has a square root with n digits; group in threes from the right for cube roots
  • Exactly 2n natural numbers lie between n2 and (n + 1)2, and none of them is a square
  • Both a perfect square and a perfect cube means a sixth power k6 — 1, 64, 729, 4096, 15625
  • (10n + 5)2 = n(n + 1) followed by 25 — so 2352 = 55225, and read backwards, √55225 = 235
  • Greatest 2n-digit perfect square has a root made of n nines: 9992 = 998001
  • a < √N < b means a2 < N < b2; a < ∛N < b means a3 < N < b3
  • ∛(−a) = −∛a — a cube root keeps the sign, a square root does not

Solved Examples — SSC CGL Square & Cube Root

Q1. Find √4489.
It ends in 9, so the root ends in 3 or 7. Striking the last two digits leaves 44, which lies between 36 and 49, so the root is in the sixties. Testing 63 gives 3969, so the root is 67. Answer: 67
Q2. Evaluate √0.00000841.
The digits are 841, whose root is 29. The number has 8 decimal places, so the root has 4. Answer: 0.0029
Q3. Find ∛(−5832).
Take the sign out: ∛(−5832) = −∛5832. The number ends in 2 and only 83 ends in 2, so the root ends in 8; striking the last three digits leaves 5, which sits between 13 and 23, so the ten digit is 1. Answer: −18
Q4. What least number must be added to 3455 to make it a perfect square?
582 = 3364 and 592 = 3481, so 3455 lies between them. The number to add is 3481 − 3455 = 26. Answer: 26
Q5. How many natural numbers lie between 172 and 182?
Between n2 and (n + 1)2 there are 2n numbers. Here n = 17, and checking directly, 289 and 324 leave 290 to 323, which is 34 numbers. Answer: 34
Q6. Find the least number by which 1080 must be multiplied to give a perfect cube, and the least number by which it must be divided to give a perfect square.
1080 = 23 × 33 × 5. For a cube, 5 needs two more copies, so multiply by 25 to reach 27000 = 303. For a square, 2, 3 and 5 all appear an odd number of times, so divide by 30 to reach 36 = 62. Answer: 25 and 30

How to Prepare Square & Cube Root for SSC CGL

  1. Learn squares to 30 and cubes to 12 first. Everything in the chapter is built on them, and no trick works without them.
  2. Drill the last-digit table until it is reflex. The last digit narrows a square root to two candidates; the decade decides. That is the whole method for four- and five-digit roots.
  3. Fix the decimal rule in one line: halve the places for a square root, divide by three for a cube root, by four for a fourth root. Mixing these up shifts the answer by a factor of ten and lands you on a distractor.
  4. Never forget the sign on a cube root. ∛(−5832) = −18. This single slip costs more marks in this chapter than anything else.
  5. Practise factorisation for the multiply and divide types. Squares need every exponent even; cubes need every exponent to reach a multiple of three.
  6. Read the last line of the question again. One stem can contain the number added, the square reached and its root — and only one of them is the answer.
  7. Do Level 1 untimed, the same day you finish the tricks. The aim is correct recall, not speed.
  8. Move to Level 2 with the 30-minute clock on. Then verify against a previous year paper and a full mock test under locked sectional timing.

SSC CGL Square & Cube Root — Frequently Asked Questions

How do I find the square root of a four-digit number without long division?
Use the last digit and the size together. The last digit narrows the root to two candidates — a square ending in 9 has a root ending in 3 or 7 — and striking off the last two digits tells you the decade. For 4489, striking 89 leaves 44, which lies between 36 and 49, so the root is in the sixties, and 672 = 4489.
How do I take the square root of a decimal?
Root the digit block, then halve the number of decimal places: a number with 2k decimal places has a root with k decimal places. So √0.00000841 = 0.0029, because 841 roots to 29 and eight places become four. For a cube root, divide the decimal places by three instead.
Can a cube root be negative?
Yes. The cube root of a negative number is negative, because a negative number cubed stays negative, so ∛(−5832) = −18. A square root, by convention, is not negative — that difference is the most common slip in this chapter.
How do I find the least number to add or subtract to make a perfect square?
Find k with k2 < N < (k + 1)2. The least number to add is (k + 1)2 − N; the least to subtract is N − k2. For 3455 the neighbouring squares are 3364 and 3481, so add 26 or subtract 91. Cubes work the same way with neighbouring cubes.
What is the least number by which a number must be multiplied to make it a perfect square?
Factorise and look at how many times each prime appears. A square needs every count even, so multiply by the primes whose count is odd: 4500 = 22 × 32 × 53, so multiplying by 5 gives 22500 = 1502. For a cube, every count must instead reach a multiple of three.
How many numbers lie between two consecutive squares?
Exactly 2n numbers lie between n2 and (n + 1)2, and none of them is a perfect square. Between 172 and 182 there are 34. Run backwards: if there are 74 such numbers, then n = 37.
How many square and cube root questions are asked in SSC CGL?
One to two in a typical Tier I shift — usually a direct root, a least number to add or subtract, or a counting question. The skills also feed simplification, surds and indices and mensuration, so the chapter is worth more practice than its direct count suggests.
